# Deploying BizFlow ERP to Render (Render.com)

This repository includes a production-ready **`render.yaml`** Render Blueprint specification that sets up both the **NestJS Backend API** (`bizflow-api`) and **Next.js Frontend App** (`bizflow-web`) automatically.

---

## 🚀 1-Click Blueprint Deployment (Recommended)

### Step 1: Sign in to Render
1. Go to [https://dashboard.render.com](https://dashboard.render.com).
2. Sign in with your GitHub account (**vinayVeddulapalli**).

### Step 2: Create New Blueprint Instance
1. Click the **+ New** button in the top right.
2. Select **Blueprint**.
3. Choose your repository: **`vinayVeddulapalli/bizFlow-erp`**.
4. Click **Connect**.

### Step 3: Configure Environment Variables
Render will read `render.yaml` and prompt you for the required secrets:
- **`DATABASE_URL`**: Your PostgreSQL connection string (from Supabase or Render PostgreSQL).
- **`DIRECT_URL`**: Your direct PostgreSQL connection string (from Supabase).
- **`JWT_SECRET`**: Automatically generated by Render (or enter a random 32-character string).
- **`JWT_REFRESH_SECRET`**: Automatically generated by Render.

### Step 4: Click "Apply"
Render will automatically build and deploy both services:
1. **`bizflow-api`**: Runs on `https://bizflow-api.onrender.com/api/v1`
2. **`bizflow-web`**: Runs on `https://bizflow-web.onrender.com`

## ⚙️ Manual Deployment (Alternative)

If you prefer to create the services individually:

### 1. Backend Service (`bizflow-api`)
- **Type**: Web Service
- **Runtime**: Node
- **Build Command**: `pnpm install --frozen-lockfile && pnpm run prisma:generate && pnpm run build:api`
- **Start Command**: `pnpm run start:api`
- **Health Check Path**: `/api/v1/health`
- **Environment Variables**:
  - `NODE_ENV`: `production`
  - `PORT`: `10000`
  - `DATABASE_URL`: *(Your Supabase connection string)*
  - `DIRECT_URL`: *(Your Supabase direct connection string)*
  - `JWT_SECRET`: *(Any secure random string)*
  - `JWT_REFRESH_SECRET`: *(Any secure random string)*

### 2. Frontend Service (`bizflow-web`)
- **Type**: Web Service
- **Runtime**: Node
- **Build Command**: `pnpm install --frozen-lockfile && pnpm run build:web`
- **Start Command**: `pnpm run start:web`
- **Environment Variables**:
  - `NODE_ENV`: `production`
  - `NEXT_PUBLIC_API_URL`: `https://bizflow-api.onrender.com/api/v1`
